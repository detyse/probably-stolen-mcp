# 公开准备评估

[English](public-readiness.md) · [使用指南](usage-guide.zh-CN.md)

检查日期：**2026-11-07**。范围为源码基线 `e5c0c40` 加上工作区中的内置帮助与文档改动。

**结论：适合作为实验性源码项目公开。** 现有证据尚不足以承诺稳定、完整的游戏覆盖。仓库可见性由所有者另行决定。

## 检查与修正

| 项目 | 发现／处理 |
| --- | --- |
| 凭据与个人路径 | 对工作区文件及已有六个可达历史提交做模式扫描，未发现类似凭据的令牌、私钥或 Windows 用户目录路径；这是限定范围检查，不是完整安全审计 |
| 依赖 | 对解决方案四个项目的直接及间接依赖运行 NuGet 漏洞审计，检查当天未报告已知漏洞 |
| 分发内容 | 未发现已跟踪的游戏 DLL、可执行文件、提取素材包、存档或连接文件；游戏库引用禁止复制，Mod 打包只允许清单与两个项目 DLL |
| 意外提交文件 | 补充连接文件、环境文件、私钥容器、二进制文件及游戏数据／存档目录的忽略规则 |
| 新用户入口 | 新增对应的中英文指南和英文 README，覆盖构建、安装、stdio 配置、首次操作、一天流程与故障处理 |
| 能力表述与来源 | 明确改名前的实机证据、当前 151 项协议检查和未验收场景；移除指向未提交生成文件的 GitHub 死链接 |
| 数据流与版权 | 说明 AI 客户端可能向模型服务商发送工具结果；区分项目 MIT 许可和验证材料中的游戏内容权利 |
| 可重复验证 | 新增 Windows CI，执行无需游戏的协议／HTTP／stdio／帮助测试，使用仓库只读权限与固定版本的 Action 提交 |
| 内置帮助 | 纳入已有的帮助实现和操作主题，使指南中的 `get_help` 用法与源码一致 |

桥接只监听本机回环，要求本次启动的令牌，拒绝浏览器 Origin 和非预期 Host，只暴露已注册游戏动作。MCP 端限制连接地址为回环，并禁用代理与重定向。这些措施缩小暴露范围，不代表已经完成全面安全审计。

官方[模组行为准则](https://github.com/dragonpan2/probably-stolen-modding/blob/main/CodeOfConduct.zh-CN.md)鼓励源码公开，要求如实描述能力与数据用途，并禁止再分发游戏源码及提取素材。证据中的实机截图与可见游戏文字保留原有权利归属。

## 标为稳定版之前

- 从新包安装更名后的 `PSMcp.*` Mod，重新跑完整的开店 → 交易 → 闭店 → 睡眠流程。
- 在[0.2.6 多职业测试](profession-tests.zh-CN.md)基础上继续验证完整鉴定、其他生产配方／生命周期、更多夜间地点及其他游戏版本，再承诺覆盖。
- 在另一台机器及客户端配置上安装验证。指南已与脚本和当前产物结构核对，尚不是独立干净电脑上的安装验收。
- 如提供二进制下载，准备带版本的包、依赖许可证说明和校验和。当前指南采用源码构建方式。

这些是稳定发布前的后续工作，不应写成已经满足的条件。公开文档本身不会改变仓库可见性，也不能证明游戏兼容性。

0.2.7 后续：[跨夜报告](overnight-tests.zh-CN.md)已确认种植、养鼠、水产和 3D 打印的实际新产物，并记录进度／生命状态与服务勾选框修复。报告只证明列出的组合，不扩大为全生产系统验收。
