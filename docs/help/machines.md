# 机器、生产与参数

共用 UI、物品槽位和参数入口已接入。0.2.6 已实测水瓶打印、搅拌机输入消耗、加热板高／关闭、水培补水和营养片、养殖槽位及刀具加工。未验证跨夜种植、繁殖、孵化或 3D 打印完成；没有全部机器的独立配方／进度模型。

1. 用当前物品打开／查看动作或场景交互打开机器。
2. get_ui_state 读取窗口、标签页、说明、参数和按钮；get_inventory 读取已呈现的槽位与内容；containers[].label 提供可见面板名称（图标槽位可能为空）。
3. 电池、模组、原料、容器等通过当前 item_move 的合法目的地装入；工具作用于目标走 item_use_on。
4. 从当前 availableActions 选择配方／模式或设置参数，逐步执行并重新观察。
5. 使用机器实际提供的启动／输出按钮。按公开进度等待，核对材料消耗、产物、数量与位置。

参数规则：开关用 toggle；滑条用 value；范围用 value 和 upperValue 且下界不能大于上界；下拉／标签页用 index；文本用 text。按本次 parameters 的 required、choices、min/max/step 校验，不能假定每种机器都使用相同控件。

净水、熔炼、酿造、种植、加工等是不同流程；耗材、兼容性、空间、电力和周期由游戏处理。实时加工与睡眠结算不能混用。没有强制完成生产或推进天数的接口；缺少专用控件适配时明确报告阻塞。

普通控件的含义和同名按钮识别见 get_help(topic="menus")。
